② Complete Pipeline Flow

1
Upload 7 Masters + 2 ERP files
Portal screen /ppc-data/upload → auto-detects table_key → parses xlsx → stores in Django DB (PPCDataRow)
2
Freeze demand from forecast
Portal screen /ppc-data/demand → upload forecast → creates PPCDemandFreeze records (immutable)
3
MPS Compute
Portal screen /ppc-data/mps → click Compute → generates mps_schedule from masters + demand. No file upload needed.
4
R3SS Compute — the deliverable
Portal screen /ppc-data/r3ss → click Compute → runs the formula:
to_plan = demand − opening + level
Where level = green_level (normal) or 0.4 × green_level (when demand < green)
Then EBQ rounding → week bucketing → day spread → PLAN + _MAP + CONTROL
5
Auto sync to Google Sheet
Django POSTs 9 payloads to n8n webhook ppc-r3ss → n8n routes by tab → clears + writes to Google Sheet.
Happens automatically after R3SS compute. HTTP 200 × 9 tabs.
6
R3SS Google Sheet — ready for the team
Sheet ID: 1AHkBgdOLO4YZO6v…rpidRDU
9 tabs populated. Planners read PLAN tab. _IMP tabs are lookup sources for formulas.

④ n8n Workflows — What to Keep & Disable

You currently have 7 PPC webhooks + 6 S&OP webhooks = 13 workflows configured. For R3SS only, you need 1.

  • KEEP
    ppc-r3ss — R3SS Sheet Sync
    Import 7-ppc-r3ss-sheet-sync-v3.json → set Google credentials on all 18 nodes → activate
  • DISABLE
    ppc-data — PPC Data sheet sync
    Was pushing all uploads to a separate PPC Data Google Sheet. Not needed — R3SS sheet has everything.
  • DISABLE
    ppc-masters — Masters sheet sync
    Was pushing L0 masters to a MASTERS Google Sheet. R3SS _IMP_MASTER tab replaces this.
  • DISABLE
    tcs-ion-erp — TCS ION ERP sync
    Was pushing all 17 ERP reports to a TCS ION sheet. R3SS only needs FG Stock + Sales Orders.
  • DISABLE
    ppc-demand — Demand sheet sync
    Was pushing demand txn to a DEMAND sheet. R3SS _IMP_DEMAND tab replaces this.
  • DISABLE
    ppc-pipeline-output — Pipeline outputs (BOM, adherence)
    L5-L8 pipeline. Not needed until those phases are built.
  • DISABLE
    ppc-planning — RM CP Packing sync
    Legacy PPC Planning sheet. Will be replaced by L7 material module.
  • SEPARATE
    sop-* (6 workflows) — S&OP module
    Different module, different team. Keep/disable based on S&OP needs — doesn't affect R3SS.

⑥ One-time Setup Checklist

  1. Open R3SS Google Sheet → verify all 9 tab names exist (exact, case-sensitive)
  2. Go to n8n → import docs/n8n/7-ppc-r3ss-sheet-sync-v3.json
  3. Open the imported workflow → set Google Sheets OAuth2 credential on all 18 nodes (9 Clear + 9 Write)
  4. Activate the v3 workflow
  5. Deactivate old workflows: ppc-data, ppc-masters, tcs-ion-erp, ppc-demand, ppc-pipeline-output, ppc-planning
  6. Test: Portal → PPC Data → R3SS → click Compute → check all 9 tabs populate in the sheet

After setup: daily workflow for planners

Morning: Upload today's FG Stock Report → Upload SO Tracking (if changed) → Go to R3SS → click Compute → done.
The sheet auto-updates. Planners open the PLAN tab and start their day.
